Scout uses a frost-colored search lens around a mint result dot. The handle
bends into a mint navigation arrow. The vector source is assets/brand/scout.svg.

bun run generate:brand renders the app and website PNGs and packages the
macOS icon sizes with Apple iconutil. The same source produces the monochrome
tray icon and the mark shown inside the app. Buddy generates the social card
from config/images.ts.
